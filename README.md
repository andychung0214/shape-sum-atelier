# 形算小工房 Shape Sum Atelier

一款可直接在瀏覽器執行的兒童圖形運算翻牌題庫。

## 遊戲介紹

形算小工房把參考練習紙中的「圖形加減」整理成規則一致的互動題庫。每個圖形由固定片段組成：

- 加法會合併左右兩個圖形的片段。
- 減法會從左側圖形移除右側已有的片段。

孩子可以先觀察與推理，再按下問號翻開答案；再次按下即可蓋回去。題目不用計時，重點是看懂每一條線如何出現或消失。

## 特色

- 80 道經程式驗證的圖形加減題。
- 初階、中階、進階、挑戰四種難度，每級 20 題。
- 每個難度都有 10 題加法與 10 題減法。
- 加法、減法或混合題型篩選。
- 具正反面的答案翻牌 toggle。
- 保存已看答案、篩選與排序偏好。
- 可使用滑鼠、鍵盤與行動裝置觸控。
- 支援減少動態效果、清楚焦點及螢幕閱讀器標籤。
- 方格紙、雙色筆與練習簿標記構成的低 AI 感視覺。
- 不使用框架、外部字型、CDN 或後端服務。

## 操作方式

1. 選擇難度與加減題型。
2. 觀察左右圖形，想像合併或移除片段後的結果。
3. 按下答案區的問號翻開答案。
4. 再按一次答案即可蓋回去。
5. 使用「換個順序」改變題目排列；按「回到原順序」可復原。
6. 使用「清除進度」移除這台裝置保存的探索紀錄。

鍵盤使用者可按 `Tab` 移動到答案，使用 `Enter` 或空白鍵翻牌。

## 安裝與執行

本專案沒有安裝步驟，也沒有套件相依。

### 直接開啟

下載或複製專案後，直接以瀏覽器開啟 `index.html`。所有樣式、程式碼與題庫都保存在專案內，離線也能使用。

### 使用本機靜態伺服器

若電腦已安裝 Python，可在專案根目錄執行：

```powershell
python -m http.server 8080
```

然後開啟 `http://localhost:8080`。

## 測試方式

需要 Node.js 18 以上版本。專案不需執行 `npm install`。

```powershell
node tests/run-tests.js
```

測試內容包括集合運算、題庫有效性、SVG 輸出、狀態復原、篩選、進度、HTML 契約、RWD 樣式契約與文件完整性。完整的瀏覽器、行動裝置及無障礙檢查項目位於 [docs/TEST-PLAN.md](docs/TEST-PLAN.md)。

瀏覽器冒煙測試必須透過本機 HTTP 或已部署的靜態網站執行，以確保測試頁面可依同源政策讀取真正首頁。啟動本機靜態伺服器後開啟：

```text
http://localhost:8080/tests/browser-smoke.html
```

頁面會載入真正的 `index.html`，自動檢查首次繪製、翻牌、篩選與重新載入，完成後在上方顯示「通過」或明確錯誤。

不要以 `file://` 直接開啟 `tests/browser-smoke.html`；部分瀏覽器會將兩個本機檔案視為不同的不透明來源。直接檔案模式請改為人工開啟專案根目錄的 `index.html` 驗收。

## 靜態網站

專案可部署至任何提供靜態檔案的服務：

- GitHub Pages
- Synology NAS Web Station
- Cloudflare Pages
- Netlify
- 一般 Nginx 或 Apache 靜態目錄

部署時將整個專案目錄複製到網站根目錄即可。不需要環境變數、重寫規則或伺服器端處理。Synology NAS Web Station 可建立「靜態網站」入口並將文件根目錄指向本專案。

## 已知限制

- 進度只儲存在目前瀏覽器的 `localStorage`，不會跨裝置同步。
- 私密瀏覽、嚴格安全設定或部分 `file://` 情境可能停用儲存；遊戲仍可操作，但重新載入後不保留進度。
- 題庫固定為 80 題，沒有內建題目編輯器。
- 圖形運算採片段集合規則，不是自由繪圖或影像辨識。
- 翻牌不播放音效，也沒有計時、分數或排行榜。
