# 形算小工房專案計畫

## 需求

- 建立可直接在瀏覽器執行的 HTML、CSS、Vanilla JavaScript 專案。
- 以參考圖的圖形加減概念製作大量、多難度題目。
- 答案預設隱藏，按下後以翻頁效果顯示，再按一次收起。
- 桌機優先，支援平板、手機、滑鼠、鍵盤與觸控。
- 可部署至不含後端的靜態網站環境。
- 提供完整文件、零相依測試、授權與 Git 紀錄。

## 範圍

### 包含

- 36 道圖形片段加減題。
- 初階、中階、進階與運算類型篩選。
- 答案翻牌、穩定亂序、探索進度及重置。
- `localStorage` 保存與錯誤復原。
- 方格紙圖形研究室視覺。
- 手機、平板、桌機三段 RWD。
- 自動測試與瀏覽器手動測試。

### 不包含

- 後端、帳號、資料庫或雲端同步。
- 題目編輯器、自由繪圖及影像辨識。
- 計時、排行榜、多人模式、音效或背景音樂。
- 框架、套件管理器與建構流程。

## 里程碑

1. 規格與技術方案：確認名稱、規則、範圍及驗收條件。
2. 圖形核心：建立片段集合、加減運算、SVG 與 36 題題庫。
3. 狀態模型：建立篩選、翻牌、進度及保存資料正規化。
4. 互動介面：建立語意化頁面、題目卡、控制列與翻牌。
5. 視覺系統：完成方格紙風格、三段 RWD 與減少動態效果。
6. 文件與品質：補齊必要文件、自動測試及秘密資料稽核。
7. 瀏覽器驗證：檢查桌機、平板、手機、鍵盤、儲存及主控台。
8. Git 發布：審查、合併，顯示推送目標後推送 GitHub。

## 工作分解

| 工作 | 主要產物 | 驗證 |
|---|---|---|
| 集合規則 | `js/core.js` | 聯集、差集及錯誤運算測試 |
| 題庫 | `js/core.js` | 片段、答案、難度及唯一性測試 |
| 狀態 | `js/state.js` | 不可變翻牌、篩選、進度及復原測試 |
| 介面 | `index.html`、`js/app.js` | HTML 契約及瀏覽器互動 |
| 視覺 | `css/styles.css` | token、斷點、翻牌及減少動態效果測試 |
| 文件 | `README.md`、`docs/` | 文件存在與必要章節測試 |
| 發布 | Git 提交與 remote | 完整測試、差異檢查及推送前確認 |

## 風險

| 風險 | 影響 | 緩解方式 |
|---|---|---|
| 題目答案與規則不一致 | 孩子學到錯誤邏輯 | 所有答案由同一 `combine` 函式計算並驗證 |
| `file://` 限制 `localStorage` | 重新載入後進度遺失 | 捕捉讀寫例外，確保當次仍能遊玩 |
| 小螢幕算式過寬 | 行動裝置無法操作 | 圖形等比例縮放、五欄算式不拆行、單欄卡片 |
| 翻牌造成暈動 | 部分使用者不適 | 支援 `prefers-reduced-motion` |
| 手作裝飾降低辨識 | 題目閱讀困難 | 只保留輕微角度與雙色筆，禁止筆畫抖動 |
| 進度資料損壞或過期 | 頁面無法載入 | 版本化、allowlist 正規化與預設值復原 |
| 靜態網站路徑錯誤 | 資源載入失敗 | 全部使用專案相對路徑，不使用根目錄絕對路徑 |

## 驗收條件

- [ ] 直接開啟 `index.html` 可看到 36 道題目且主控台無錯誤。
- [ ] 每題答案預設隱藏，可用滑鼠、觸控、Enter 及空白鍵來回翻牌。
- [ ] 三種難度均包含加法與減法，所有答案通過規則驗證。
- [ ] 篩選、亂序及重置可正常操作。
- [ ] 儲存可用時，重新載入後保留進度與偏好。
- [ ] 儲存不可用或資料損壞時，遊戲仍可操作。
- [ ] 390px、820px 及 1440px 寬度沒有水平捲動。
- [ ] 減少動態效果模式可立即切換答案。
- [ ] `node tests/run-tests.js` 全數通過。
- [ ] README、計畫、藝術方向、測試計畫、貢獻指南、忽略規則及授權均存在。
