## 自動測試

執行：

```powershell
node tests/run-tests.js
```

### 核心邏輯

- [ ] 加法依序建立片段聯集。
- [ ] 加法不重複片段。
- [ ] 減法建立左側與右側的差集。
- [ ] 未知運算會回報錯誤。
- [ ] SVG 包含正確名稱及片段數。

### 題庫品質

- [ ] 至少有 30 題及 12 種片段。
- [ ] 題目識別碼唯一。
- [ ] 所有片段都存在。
- [ ] 左右運算元及答案皆非空。
- [ ] 減法右側是左側子集合。
- [ ] 所有答案與集合運算結果一致。
- [ ] 初階、中階、進階都同時有加法及減法。

### 狀態與文件

- [ ] 翻牌不修改原始狀態。
- [ ] 未知題目紀錄會被移除。
- [ ] 損壞或不相容版本會使用預設值。
- [ ] 篩選及進度計算正確。
- [ ] HTML、CSS、腳本及必要文件符合契約。

## 功能手動測試

- [ ] 初次開啟時所有答案皆為問號。
- [ ] 按一次問號翻到答案，再按一次翻回問號。
- [ ] 快速連按同一答案不會卡在中間狀態。
- [ ] 難度篩選只留下所選難度。
- [ ] 運算篩選只留下所選運算。
- [ ] 雙重篩選可同時生效。
- [ ] 換個順序後題目改變排列，再按可回原順序。
- [ ] 篩選與排序不會清除已看答案紀錄。
- [ ] 清除進度選擇取消時維持原狀。
- [ ] 清除進度選擇確認時回到預設狀態。
- [ ] 重新載入後保留進度與篩選。
- [ ] 停用儲存或令儲存拋出例外時仍可翻牌。
- [ ] 沒有符合題目時顯示引導按鈕。
