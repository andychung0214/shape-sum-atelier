# 形算小工房藝術方向

## 可選視覺風格

| 方向 | 材質與語氣 | 優點 | 取捨 |
|---|---|---|---|
| 方格紙圖形研究室（採用） | 方格紙、雙色筆、老師的練習紙 | 最貼近題型來源，規則一眼可懂 | 手作感必須克制，避免凌亂 |
| 蒙特梭利木質教具 | 木盤、實體拼片、柔和原色 | 親切、適合低齡孩子 | 容易變成一般幼兒教材 |
| 夜間藍圖實驗室 | 深藍底、粉筆線、精密標記 | 對比鮮明、較有挑戰感 | 氣氛偏冷，不適合長時間閱讀 |
| 和紙圖形研究室 | 和紙、墨線、落款印章 | 日式質感最鮮明 | 若裝飾過多會削弱題目辨識 |

## 採用方向

首版採用「方格紙圖形研究室」。畫面像一張放在木桌上的老師手寫練習紙：題目用酒紅筆，答案用靛青筆，資訊標記使用鉛筆灰。唯一強烈的互動特徵是答案小紙片沿 Y 軸翻面，其餘元件保持安靜。

本方向融合日式極簡與輕度侘寂，但不使用常見的米白加襯線字模板。辨識性來自教室裡真實存在的方格紙、雙色筆、題號、練習紙編號與略微不齊的紙片，而不是抽象裝飾。

## 色票

| Token | 色值 | 用途 |
|---|---|---|
| `--wood` | `#a98762` | 桌面基底 |
| `--wood-dark` | `#775b42` | 木紋陰影 |
| `--paper` | `#f6f1e5` | 主紙張 |
| `--paper-deep` | `#ebe2cf` | 答案紙片與工具列 |
| `--grid-line` | `rgba(71, 89, 92, 0.13)` | 方格線 |
| `--ink` | `#272923` | 標題與主要文字 |
| `--ink-soft` | `#64645d` | 輔助資訊 |
| `--ink-red` | `#8f2944` | 題目圖形、提示與危險操作 |
| `--ink-blue` | `#294a8a` | 答案、進度與主要操作 |
| `--focus` | `#d97724` | 鍵盤焦點 |

所有主要文字、控制元件與圖形都需在紙張底色上維持清楚對比。顏色不是唯一狀態線索：按鈕同時使用文字、外框、翻面與 `aria-expanded`。

## 字體策略

- 標題：`"Yu Gothic", "Hiragino Kaku Gothic ProN", "Noto Sans TC", sans-serif`
- 正文：`"Noto Sans TC", "Microsoft JhengHei", sans-serif`
- 題號與工具資訊：`ui-monospace, "SFMono-Regular", Consolas, monospace`

不下載外部字型。粗體標題刻意縮短字距，產生像練習簿封面的緊實感；正文維持正常字距與至少 1.6 倍行高。

## 版面與元件

### 紙張

- 最大寬度 88rem，桌面四周保留木桌。
- 由兩組 1px 漸層形成 1.25rem 方格。
- 左側有淡酒紅裝訂線，但不可干擾文字。
- 陰影只有紙張與需要按壓的控制元件使用。

### 題目卡

- 手機單欄、平板雙欄、桌機三欄。
- 邊線為鉛筆灰，背景延續較細方格。
- 只允許 ±0.2 度的輕微角度差，不使用大幅旋轉。
- 算式保持同一列，不將運算符號拆行。

### 圖形

- 所有圖形共用 100 × 100 SVG 座標。
- 圖形線寬為 5，圓頭、圓角接合。
- 題目使用酒紅色，答案使用靛青色。
- 不使用陰影、立體描邊或隨機筆畫抖動。

### 答案小紙片

- 使用原生 `button`，最低 44 × 44 CSS 像素。
- 正面顯示問號與「揭曉」，背面顯示答案圖形。
- 翻開後文字改為「收起」，`aria-expanded` 同步為 `true`。
- 焦點外框使用橙色，不被紙片裁切。

### 篩選與操作

- 下拉選單像練習紙上的表格欄位。
- 主要操作使用靛青底，清除進度使用酒紅外框。
- 選項保持明確動詞，不使用只有圖示的按鈕。

### 進度

- 同時顯示目前題數、已看答案數與百分比。
- 進度條使用靛青斜線筆觸，但不連續移動。

## 動畫原則

- 翻牌時間為 420ms，使用 `cubic-bezier(0.2, 0.72, 0.25, 1)`。
- 翻牌只沿 Y 軸，不加彈跳、粒子或發光。
- 進度條寬度變化為 240ms。
- `prefers-reduced-motion: reduce` 時所有動畫縮短為 0.01ms，並停用平滑捲動。

## 禁止事項

- 不使用玻璃擬態、霓虹光、發光外框或高飽和漸層。
- 不使用 emoji 代替功能圖示。
- 不將所有容器做成大圓角卡片或膠囊。
- 不使用無內容意義的編號、徽章或統計裝飾。
- 不使用連續漂浮、呼吸、閃爍或頁面載入動畫。
- 不使用外部字型、外部圖片或網路請求。
- 不仿製參考圖中的人物手部、品牌文字或攝影背景。
