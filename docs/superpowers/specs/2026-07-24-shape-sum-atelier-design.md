# 形算小工房設計規格

## 產品定位

- 英文名稱：Shape Sum Atelier
- 中文名稱：形算小工房
- 類型：兒童圖形運算翻牌題庫
- 主要平台：桌機瀏覽器，支援平板與行動裝置觸控
- 執行方式：不需安裝或建構，直接開啟 `index.html` 即可使用

形算小工房將參考圖中的「圖形筆畫加減」轉化為可重複遊玩的題庫。孩子先觀察兩個圖形與運算符號，再按下答案區，透過翻頁動畫揭露答案；再次按下則收起答案。首版重點是讓規則一致、操作直覺、畫面安靜，並能在靜態網站託管環境中完整執行。

## 設計目標

1. 孩子能在沒有文字說明的情況下理解題目結構。
2. 每道題目的答案都能由明確的圖形集合規則推導。
3. 答案預設隱藏，滑鼠、觸控及鍵盤皆可切換顯示狀態。
4. 題庫具有足夠的難度層次，且可依難度與運算類型篩選。
5. 畫面保留紙筆手作感，但不犧牲辨識度、效能與無障礙。
6. 專案不依賴框架、套件管理器、外部字型或網路連線。

## 範圍

### 首版包含

- 三個難度層級：初階、中階、進階。
- 加法與減法兩類圖形運算。
- 至少 30 道可驗證題目。
- 題目卡與答案翻牌 toggle。
- 難度及運算類型篩選。
- 已探索題數與完成比例。
- 使用 `localStorage` 保存已揭曉題目及偏好。
- 題庫重置功能。
- 桌機、平板與手機三組響應式版面。
- 鍵盤操作、清楚焦點樣式、螢幕閱讀器標籤及減少動態效果模式。
- 不依賴大型框架的自動測試與完整手動測試清單。

### 首版不包含

- 使用者帳號、雲端同步、後端服務及資料庫。
- 計時競賽、分數排行榜及多人模式。
- 題庫編輯器或自訂題目上傳。
- 音效、背景音樂及語音提示。
- 需要建構流程的壓縮或最佳化工具。

## 圖形運算規則

每個圖形由固定座標系統中的「圖形片段集合」組成。片段包含水平線、垂直線、斜線、圓弧與中心記號，每個片段都有穩定識別碼與 SVG 路徑。

- 加法 `A + B`：答案為兩個片段集合的聯集；重複片段只顯示一次。
- 減法 `A − B`：答案為 A 中移除 B 所含片段後的差集。
- 題目不得產生空白答案。
- 題目中的左右運算元不得為空白圖形。
- 減法右側只能使用左側已包含的片段，確保語意直覺。
- 題庫建立時執行驗證，避免重複題目、無效片段或答案不一致。

初階題目使用少量、互不重疊的片段；中階加入重疊片段及減法；進階使用較多片段、混合方向與較相似的干擾外觀。所有題目仍遵守相同集合規則，不用視覺猜謎取代邏輯。

## 資訊架構

單頁內容由上而下排列：

1. 品牌標頭：名稱、簡短說明與紙張編號。
2. 學習摘要：目前顯示題數、已探索題數、完成比例。
3. 控制列：難度、運算類型、隨機排序及重置。
4. 題庫格線：依篩選結果呈現題目卡。
5. 空結果提示：沒有符合條件時提供恢復全部篩選的按鈕。
6. 頁尾：操作提示、離線說明及版本資訊。

桌機以三欄題目卡為主，平板為兩欄，手機為單欄。控制列可換行，不使用需要精準拖曳的互動。

## 元件邊界

### 題庫模型

負責圖形片段、集合運算、題目資料、難度與題庫驗證。它不直接操作 DOM，可在 Node.js 測試環境執行。

### 圖形繪製器

接收片段識別碼並建立 SVG。它只處理圖形輸出、筆畫色彩與輔助的無障礙描述，不管理題目狀態。

### 題目卡

顯示左右運算元、運算符號與答案區。答案區使用原生 `button`，以 `aria-expanded`、可見文字及翻牌狀態同步表達目前狀態。

### 題庫控制器

管理篩選、排序、翻牌、進度及畫面更新。事件採集中式委派，避免每次重新繪製後累積監聽器。

### 偏好儲存

封裝 `localStorage` 讀寫、資料版本及錯誤復原。如果瀏覽器停用儲存功能，遊戲仍可在當次工作階段操作。

## 互動與資料流

1. 頁面載入後驗證題庫並讀取已保存狀態。
2. 控制器依篩選條件取得題目，交由圖形繪製器與題目卡輸出。
3. 使用者按下答案按鈕後，控制器切換該題揭曉狀態。
4. UI 更新 `aria-expanded`、按鈕提示、正反面及學習摘要。
5. 狀態寫入 `localStorage`；寫入失敗不阻止互動。
6. 篩選或重新排序只改變顯示順序，不清除已揭曉紀錄。
7. 重置前使用原生確認對話框，確認後清除題目進度並重新繪製。

## 視覺方向

採用「方格紙圖形研究室」，融合日式極簡與輕度侘寂：

- 背景為暖木色抽象紋理，內容區像放在桌面的米白方格紙。
- 算式使用酒紅色，答案使用靛青色，對應參考圖的雙色筆跡。
- 文字採本機日系無襯線字型堆疊，不載入外部字型。
- 卡片以細線、紙張裁切與輕微角度差異建立手作感，不使用大量圓角膠囊。
- 控制元件像紙標籤或印章，但維持足夠點擊尺寸與清楚狀態。
- 動畫使用約 420 毫秒的 3D 翻頁，減少動態效果模式則立即切換。

可選但不套用的方向為「蒙特梭利木質教具」與「夜間藍圖實驗室」。前者較像幼兒教材，後者對低齡孩子較不溫暖，因此首版不採用。

## 錯誤與邊界處理

- 題庫驗證失敗時，顯示可理解的錯誤區塊，不輸出破損題目。
- 儲存資料格式錯誤或版本不符時，忽略舊資料並使用預設狀態。
- `localStorage` 讀寫例外會被捕捉，介面仍可操作。
- 無 JavaScript 時顯示需啟用 JavaScript 的提示。
- 沒有篩選結果時不留下空白頁面。
- 快速連續按下答案按鈕時，以目前布林狀態為準，不建立動畫佇列。
- 小螢幕上的算式會縮放但不換行拆散，最低觸控目標維持 44 × 44 CSS 像素。

## 測試策略

### 自動測試

使用 Node.js 內建測試工具或單一可執行測試腳本，不安裝測試框架。測試涵蓋：

- 聯集與差集運算。
- 重複片段去除及輸出順序穩定性。
- 題庫所有片段有效、答案非空、答案與運算結果一致。
- 題目識別碼唯一及三個難度皆有加減題。
- 儲存狀態正規化與損壞資料復原。
- 篩選及完成比例計算。

### 瀏覽器驗證

- 直接以 `file://` 開啟 `index.html`。
- 另以本機靜態伺服器確認託管情境。
- 驗證桌機、平板及手機尺寸。
- 以滑鼠、觸控模擬及鍵盤操作翻牌。
- 檢查重新載入後進度、篩選與偏好是否保留。
- 檢查焦點順序、名稱角色值、色彩對比及減少動態效果。
- 檢查控制台沒有錯誤，且沒有失敗的外部網路請求。

## 驗收條件

1. 直接開啟 `index.html` 即可看見並操作完整題庫。
2. 首頁至少提供 30 道有效題目，涵蓋三種難度及加減運算。
3. 每張答案卡預設隱藏，滑鼠、觸控及鍵盤皆可來回翻牌。
4. 所有答案皆通過與集合運算規則一致的自動測試。
5. 桌機、平板與手機版面無水平捲動或不可操作元件。
6. 重新載入頁面後已揭曉進度仍保留；儲存不可用時仍可遊玩。
7. 專案包含需求指定的文件、測試、忽略規則及授權。
8. Git 提交訊息符合 Conventional Commits，描述使用 zh-TW。
9. 只有在有效 remote 存在且已顯示 remote、branch 與 commit 後才執行推送。
